# AI's Eye Supervisor Dashboard Design

## 적용 범위

이 문서는 `apps/dashboard/src/components/head-office` 아래의 슈퍼바이저용 본사
대시보드에만 적용한다. 점주용 실시간 매장 화면, 로그인, 설정 화면에는 적용하지 않는다.

IBM의 공개 화면을 분석한
[IBM DESIGN.md](https://getdesign.md/ibm/design-md)를 참고하되 IBM 브랜드나 로고를
복제하지 않고 AI's Eye의 본사 운영 분석 목적에 맞게 사용한다.

## 목표

슈퍼바이저가 10초 안에 다음 세 가지를 파악할 수 있어야 한다.

1. 어느 매장이 운영상 눈에 띄는가
2. 그 판단에 사용된 수치는 무엇인가
3. 본사 또는 매장이 취할 수 있는 조치는 무엇인가

이 화면은 실시간 CCTV 관제 화면이 아니다. 기간별 집계, 매장 비교, AI 운영 제안을
제공하는 분석 화면이다.

본사 로그인은 `/hq` 전용 주소와 `AI's Eye HQ` 헤더를 사용한다. 점주용 매장 전환
탭이나 점주용 사이드바를 본사 화면에 노출하지 않는다.

## 시각 원칙

- 흰색과 중성 회색을 중심으로 데이터 밀도가 높은 기업용 화면을 만든다.
- IBM Blue 계열은 선택 상태, 주요 동작, AI 분석 영역에만 사용한다.
- 카드의 큰 둥근 모서리, 유리 효과, 강한 그림자, 장식용 그라데이션을 사용하지 않는다.
- 영역은 1px 테두리와 배경 명도 차이로 구분한다.
- 이모지는 사용하지 않는다. 상태는 색상과 텍스트를 함께 표시한다.
- 가짜 실시간 표시, 가짜 수치, 의미 없는 차트는 사용하지 않는다.

## 색상

| 역할 | 값 | 용도 |
|---|---|---|
| Primary | `#0F62FE` | 주요 버튼, 활성 탭, 포커스 |
| Primary hover | `#0353E9` | 주요 버튼 hover |
| Primary pressed | `#002D9C` | 주요 버튼 active |
| Canvas | `#F4F4F4` | 전체 배경, 보조 표면 |
| Surface | `#FFFFFF` | 섹션, 표, 카드 |
| Border | `#E0E0E0` | 테두리와 구분선 |
| Text | `#161616` | 제목과 본문 |
| Text muted | `#525252` | 설명, 보조 정보 |
| Success | `#198038` | 정상 상태 |
| Warning | `#B28600` | 점검 필요 |
| Danger | `#DA1E28` | 오류, 높은 위험 |

## 타이포그래피

- 한글 우선 글꼴: `Pretendard`, `Noto Sans KR`, `Segoe UI`, `sans-serif`
- 페이지 제목: 32–48px, 400
- 섹션 제목: 24px, 400
- 본문: 14–16px, 400
- 표와 보조 정보: 12–14px
- 숫자는 표에서 오른쪽 정렬하고 tabular number를 사용한다.
- 영문 대문자는 짧은 섹션 키커에만 사용한다.

## 간격과 형태

- 기본 간격: 8, 12, 16, 24, 32, 48px
- 컨트롤 최소 높이: 48px
- 기본 모서리: 0px
- 상태 태그 등 작은 요소에만 2–4px 허용
- 화면 최대 폭: 1440px
- KPI는 넓은 화면 4열, 중간 화면 2열, 작은 화면 1열
- 비교표는 모바일에서 가로 스크롤을 허용한다.

## 컴포넌트 규칙

### 본사 전용 헤더

- 메뉴는 `운영 개요`, `가맹점 분석`, `AI 인사이트`로 구성한다.
- 각 메뉴는 같은 본사 페이지의 해당 영역으로 이동한다.
- 우측에는 본사 사용자 정보와 로그아웃만 표시한다.
- 점주 화면, 실시간 CCTV, 설정으로 전환하는 버튼을 두지 않는다.

### 기간 필터

- 현재 선택된 기간만 파란 배경과 흰 글자로 표시한다.
- 직접 설정은 한국시간 입력값을 ISO 8601로 변환한다.
- 기간 변경 시 기존 AI 결과를 지워 과거 결과로 오인하지 않게 한다.

### KPI

- 한 카드에는 하나의 핵심 숫자만 크게 표시한다.
- `데이터 없음`과 실제 `0`을 구분한다.
- 비교 기준이 되는 매장명과 수치를 함께 표시한다.

### 비교표

- 매장명, 인원, 대기, 주문, 인기 메뉴, 영상 상태, 최신 시각을 표시한다.
- 상태는 텍스트를 포함한 태그로 표시한다.
- 수치는 오른쪽 정렬한다.

### AI 인사이트

- 사용자가 버튼을 누를 때만 생성한다.
- 결과는 `판단 → 근거 → 권장 조치` 순서로 표시한다.
- AI 오류는 집계 영역과 분리하며 기존 집계 데이터 사용을 막지 않는다.
- 아직 구현되지 않은 이상 탐지 점수는 화면에 표시하지 않는다.

## 금지 사항

- 슈퍼바이저 화면에서 2초 Polling 또는 CCTV 영상 표시
- “100% 실시간”, “즉시 조치”처럼 역할과 맞지 않는 표현
- 백엔드에 없는 시계열 차트나 이상 탐지 값 생성
- 원시 JSON을 그대로 화면에 노출
- 색상만으로 정상·경고·오류를 구분
- 전역 CSS 선택자로 점주 화면 스타일 변경
