# 발견된 이슈

| 화면 | 문제 | 재현 방법 | 담당 |
|------|------|-----------|------|
| 점주 | 상단 매장명은 강남점인데 정책은 동명점으로 표시됨 | 점주 로그인 → 매장1 선택 → 정책 영역 확인 | Front |
| 점주 | 서버 연결 시 메뉴 및 매장 정책 데이터가 표시되지 않음 | 서버 환경 실행 → 점주 로그인 → 메뉴·정책 영역 확인 | API |
| 점주 | Vision 지원 범위와 화면 표시가 일치하는지 확인 필요 | 점주 로그인 → 매장 현황 → 구역별 실시간 인원 확인 | Front |
| 슈퍼바이저 | 실시간·동기화 문구와 실제 동작이 일치하는지 확인 필요 | 슈퍼바이저 로그인 → 통합 관제 화면 확인 | 기획 |
