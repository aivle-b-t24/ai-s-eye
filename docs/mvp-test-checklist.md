# MVP QA 테스트 체크리스트

## 목적

점주 및 슈퍼바이저 화면의 MVP 기능을 검증하고, 실제 API 데이터와 화면 표시값이 일치하는지 확인한다.

---

# 점주 화면

## 1. 매장 선택

- [ ] store-001 / store-002가 정상적으로 구분된다.
- [ ] 매장 변경 시 화면 정보가 정상 변경된다.

## 2. 매장 현황

- [ ] 전체 인원이 정상 표시된다.
- [ ] 대기 인원이 정상 표시된다.
- [ ] ETA(예상 대기 시간)가 정상 표시된다.
- [ ] API 값과 화면 값이 일치한다.

## 3. 메뉴

- [ ] 메뉴 목록이 정상 표시된다.
- [ ] 품절 메뉴가 정상 표시된다.
- [ ] 품절 사유가 표시된다.

## 4. 매장 정책

- [ ] 정책 정보가 정상 표시된다.
- [ ] JSON 데이터와 화면이 일치한다.

## 5. API 상태

- [ ] 정상 연결 상태를 확인한다.
- [ ] API 연결 실패 상태를 확인한다.
- [ ] 오류 메시지가 정상 표시된다.
